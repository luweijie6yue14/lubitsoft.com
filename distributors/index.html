Windows Keygen Tool

Windows 激活码生成器（LubitSoftKeygen）介绍

LubitSoftKeygen 是专为官方授权分销商打造的 Windows 桌面端正版激活码签发工具，采用现代加密签名技术与高 DPI 原生界面设计，兼顾安全性与出码效率。

🔐 Ed25519 非对称数字签名

基于 Ed25519 椭圆曲线签名与设备机器码精确绑定，生成的激活码不可伪造、不可篡改，确保正版验证安全可靠。

🖥️ 原生高 DPI 桌面界面

基于 PySide6 构建的轻量级 Windows 桌面客户端，支持深色/浅色主题与高分辨率屏幕清晰显示，输入机器码与选择期限即可出码。

🔒 口令校验与单机设备锁定

内置 PBKDF2-HMAC-SHA512 高强度口令保护及分销商单机设备绑定机制，防止生成器外泄与未授权使用。

📜 完整出码历史与审计记录

自动记录每次激活码生成时间、对应机器码及授权时长，方便分销商对账管理与客户售后查询。
