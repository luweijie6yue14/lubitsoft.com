Software Overview

软件简介与核心特性

PureDasher 采用原生 Kotlin 与 Jetpack Compose 倾力打造，专为追求极致轻盈与透明掌控感的 Android 用户设计。软件集成了精密的电池库仑计健康监测服务、一站式设备状态中心以及五种桌面微件，所有核心数据均在设备本地实时演算呈现。

🔋 电池健康库仑计监测

内置轻量级前台监测服务，精确追踪充放电电流、电池温度、循环健康度与预估续航，支持自定义充电保护提醒。

🧩 5 种比例桌面微件矩阵

原生提供 2×1 极简胶囊、2×2 紧凑方格、4×1 极简横条、4×2 详细仪表盘与 4×3 全景监控面板，完美适配各类桌面布局。

🛡️ 透明设备权限中心

清晰展示网络、定位、通知及电池优化状态，支持一键直达系统设置开启或关闭可选进阶权限，绝不强制索权。

🌐 轻量化多语言引擎

支持在线多语言包即时切换与 Material 3 动态取色主题，安装包小巧纯净，无任何第三方广告 SDK。
