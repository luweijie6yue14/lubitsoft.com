Software Overview

软件详情与核心特性

LubitSoft LED 延续了 LubitSoft 2048 广受好评的硬件级点阵 LED 渲染质感（暗底 PCB、未点亮灯珠孔位、外圈光晕、亮芯高光与玻璃反光），将其扩展为一款全功能跨平台虚拟 LED 显示屏工具，支持 Windows 桌面与 Android 手机平板通过局域网实时联动。

📟 四大显示模式与硬件级点阵渲染

支持跑马灯滚动（Marquee）、静态居中（Static）、5×7 点阵数字时钟（Clock）以及交互式像素画板（Draw），中英文、日韩泰等 Unicode 字符均可清晰点阵化显示。

🎨 全面自定义像素、比例与灯珠外观

支持 16×7 至 128×48 任意像素网格、多种屏幕比例（Auto / 16:9 / 21:9 / 4:1 / 1:1 / 自定义）、任意 Hex 颜色、圆形/方形贴片灯珠与亮度调节。

🖥 Windows 实时动态桌面壁纸（最高 8K）

支持将 LED 屏幕实时设为 Windows 动态桌面壁纸，自动匹配屏幕比例，最高支持 8K 显示器，并支持同步主屏或独立配置壁纸内容。

🔗 局域网双向确认同步 & 11 国语言

同一 Wi-Fi 下自动发现设备，双方均点击确认配对后即可实时双向同步；Android 端全面适配挖孔屏安全区与滑动返回退出全屏，原生支持 11 种语言。
